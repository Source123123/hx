name: load
description: 用 hx 载入项目保存的 Agent 环境，或在换机器、换 Agent 时接手带有 .harness 的项目。
---

启动器位于本技能目录向上两层的 `bin/`。从本技能实际路径确定插件根目录，
在用户项目目录执行。macOS、Linux、Git Bash 使用 `"<插件根目录>/bin/hx"`；
Windows PowerShell 使用 `& "<插件根目录>\bin\hx.cmd"`，命令提示符不需要 `&`。
全部操作通过这个启动器执行，不要求 pip 安装。

先运行 `load --dry-run`（用户提供来源时附加来源），简要说明会写入哪些文件、有哪些冲突。
载入的设置可能带有可执行命令，只应载入用户信任的来源。写入前需要明确授权；
本轮或此前已经明确授权载入这份配置时直接继续，否则等待用户确认。
有授权后执行 `load --yes`，已有不同文件默认保留；未经明确授权不要加 `--force`。

逐条说明缺少的环境变量、工具和插件，以及旧记忆中在本机尚未核实的外部状态。
不要索要密钥原文，不要自动执行包里的重建命令，不要自动安装包里的插件或信任钩子。
阅读 `.harness/context/HANDOFF.md`，概括项目进展与待办。新技能和指令可能需要新开 Codex 会话才可用。
