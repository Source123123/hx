---
name: save
description: 保存当前项目的 Agent 配置、技能和工作进展。用户要求用 hx 保存、创建环境快照或交接项目时使用。
---

保存当前项目的 Agent 环境。启动器位于本技能目录向上两层的 `bin/`。
先从本技能的实际文件路径确定插件根目录，保留当前工作目录为用户的项目。
macOS、Linux、Git Bash 调用 `"<插件根目录>/bin/hx" save`；
Windows PowerShell 调用 `& "<插件根目录>\bin\hx.cmd" save`，命令提示符不需要 `&`。
不要依赖系统是否安装了 hx，不要用 pip 安装。

保存前，若本次工作依赖项目外的数据库、服务或本机工具，通过同一启动器的
`claim add "说法" [--path 路径|--env 变量名|--command 工具名]` 登记。
若有向量库或索引，使用 `resource add 名字 --path 产物 --sources "源文件模式" --build "重建命令"`
登记，避免把数据复制进包。仅在确有这些依赖时处理。

用一两句话说明保存结果和提醒。自动保存只提交 `.harness/`，不推送；用户要求推送时先运行 `audit`，
把发现的内容交给用户判断。首次保存可说明 `team on` 的用途，用户要求团队接入时才开启。
