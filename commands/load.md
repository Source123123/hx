---
description: 把项目里保存的 Agent 环境载入这台机器，并检查缺什么
allowed-tools: Bash
---

按下面的步骤帮用户载入项目的 Agent 环境。全程用用户的语言，说人话，不要让用户自己敲命令。

1. 先预演，看会往本机放哪些文件：

   ```
   "${CLAUDE_PLUGIN_ROOT}/bin/hx" load --dry-run $ARGUMENTS
   ```

2. 把列表简要告诉用户，并说明：这些配置来自这个项目，其中的设置可能包含会自动执行的命令，只应载入信任的项目。等用户明确同意后再继续。如果列表为空，直接进行下一步。

3. 用户同意后载入：

   ```
   "${CLAUDE_PLUGIN_ROOT}/bin/hx" load --yes $ARGUMENTS
   ```

4. 输出里"还需要你处理"的每一项，逐条用一句话告诉用户该怎么做（例如缺哪个环境变量、要装哪个插件），能由你代劳的就提出代劳。不要让用户把密钥贴到对话里。

5. 最后阅读 `.harness/context/HANDOFF.md`，用三五句话向用户概括这个项目目前的进展和待办。
